# Provider marks (#78)

`src/renderer/lib/provider-logos.json` is generated by `node scripts/gen-provider-logos.mjs`
from the pinned Iconify packages already used for project icons and the local ChatGPT SVG below. No network requests at runtime.
SVG bodies come only from these fixed sources, never account data. The Iconify sets are MIT; full
notices are in [licenses/devicon.txt](licenses/devicon.txt) and
[licenses/material-icon-theme.txt](licenses/material-icon-theme.txt). Trademarks remain with
their owners. These small marks identify the CLI an account runs; they do not imply endorsement.

Reviewed 2026-10-24:

| CLI | Bundled asset / fallback | Brand reference |
| --- | --- | --- |
| Claude | Devicon `claude`, original colour | [Anthropic legal / trademark guidelines](https://www.anthropic.com/legal) |
| Codex | ChatGPT/OpenAI knot, monochrome foreground; Simple Icons 14.15.0 `openai` | [OpenAI brand terms](https://openai.com/brand/) |
| Antigravity | Devicon `antigravity`, original colours | [Google brand guidance](https://about.google/brand-resource-center/guidance/) |
| Gemini | Material Icon Theme `gemini-ai`, original colour | [Google brand guidance](https://about.google/brand-resource-center/guidance/) |
| Cursor | Devicon `cursor`, monochrome foreground for both themes | [Cursor brand assets](https://cursor.com/brand) |
| Copilot | Letter fallback; bundled set has the deprecated standalone logo | [GitHub Copilot brand toolkit](https://brand.github.com/brand-identity/copilot) |
| OpenCode | Material Icon Theme `opencode`, original colours | [OpenCode brand assets](https://opencode.ai/brand) |

Provider names live in `AGENT_CLI_SPECS.providerLabel`. Unavailable/unknown assets fall back
to the provider initial in chips, group headers and dividers. Account avatars keep the
account initial, with a small provider mark at its corner.

The Codex mark uses [Simple Icons 14.15.0's OpenAI SVG](https://github.com/simple-icons/simple-icons/blob/14.15.0/icons/openai.svg),
vendored at `src/renderer/lib/provider-logo-chatgpt.svg` so regenerating the provider subset stays offline.
Its CC0 notice is in [licenses/simple-icons.txt](licenses/simple-icons.txt); the OpenAI mark belongs to OpenAI
and is used only to identify the account provider, following the linked brand guidelines.
